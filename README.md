# Organizza la tua giornata

##Introduzione

Questo codice, scritto con Python, ci permette di riordinare le attività della nostra giornata.
Il giocatore riordina all'interno delle caselle le immagini che rappresentano le attività corrispondenti all'orario soprastante.
Il gioco termina quando il giocatore posiziona i momenti della giornata nell'ordine corretto.

###Funzionalità

Il codice permette di:
-Scegliere un'immagine e trascinarla in una casella.
-Modficare l'ordine delle immagini prima di finire .
-Analizzare che sia corretto l'ordine tramite il comando "Controlla".
-Ripristinare l'ordine in caso il giocatore abbia sbagliato permettendogli di ritentare.
-Terminare la partita quando l'ordine è corretto.

##Installazione

###Prerequisiti
E'necessario avere installato un compilatore Python e Pycharm, un IDE destinato alla programmazione nel linguaggio Python.

###Per installare il progetto è necessario:
1.Scaricare il file sorgente.
2.Aprirlo tramite un compilatore Python.
3.Compilare ed eseguire il codice.

##Utilizzo

-Avviare il programma.
-Selezionare e trascinare le immagini in una casella.
-Cliccare su "Controlla" per sapere se è stato fatto tutto correttamente.

##Cosa migliorare

Nonostante il codice viene eseguito correttamente, ci sono alcune cose che possono essere migliorate:
-Una volta finita la partita le immagini rimangono sempre le stesse, perciò la giornata non è personalizzabile, bensì segue uno schema analogo per tutti i giorni della settimana.
